# Assignment 6: Task Manager with Routing

A robust Single Page Application (SPA) built using React Router for comprehensive task management.

## Features Included
- **React Router Navigation**: Seamless client-side routing with `react-router-dom` (HashRouter for GitHub Pages compatibility).
- **Protected Routes**: Basic authentication wrapper guarding dashboard and task routes.
- **Dynamic URL Parameters**: View specific task details using dynamic routing (`/tasks/:id`).
- **Full CRUD Operations**: Create, Read, Update (Status), and Delete tasks.
- **Task Analytics Dashboard**: Overview of total, pending, raised, and completed tasks.
- **Filtering**: View all tasks or filter by categories like Academic/Personal.
- **Modern UI**: A responsive, sidebar layout with a sleek dark aesthetic and beautiful badge elements.

## Setup Instructions

1. Clone the repository:
   ```bash
   git clone https://github.com/soumyadeep231001102218/assignment-6-task-manager.git
   ```

2. Navigate into the project directory:
   ```bash
   cd assignment-6-task-manager
   ```

3. Install the dependencies:
   ```bash
   npm install
   ```

4. Start the development server:
   ```bash
   npm run dev
   ```

5. Open your browser and visit the live deployment to view the site: [https://soumyadeep231001102218.github.io/assignment-6-task-manager/](https://soumyadeep231001102218.github.io/assignment-6-task-manager/)
